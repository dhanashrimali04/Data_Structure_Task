# Python Data Structure Tasks

## 📌 About the Project

This repository contains four beginner-friendly Python mini-projects created to practice fundamental Python data structures and improve programming logic.

These projects demonstrate the use of **Lists, Tuples, Dictionaries, and basic To-Do List functionality** in Python.

## 📂 Projects Included

### 1. List Operations (`List.py`)
- Demonstrates the use of Python lists.
- Helps practice storing and managing collections of items.
- Introduces basic list operations.

### 2. Tuple Operations (`Tuple.py`)
- Demonstrates the use of Python tuples.
- Explores ordered and immutable collections.
- Helps understand the difference between lists and tuples.

### 3. Dictionary Operations (`Dict.py`)
- Demonstrates Python dictionaries using key-value pairs.
- Helps practice storing and accessing structured data.
- Introduces basic dictionary operations.

### 4. To-Do List (`To_Do_list.py`)
- A simple task-management mini-project.
- Demonstrates basic task organization using Python.
- Helps improve problem-solving and programming logic.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Concepts:** Lists, Tuples, Dictionaries, Data Structures, Basic Programming Logic

## 🚀 How to Run the Projects

### Step 1: Clone the Repository

```bash
git clone https://github.com/dhanashrimali04/Data_Structure_Task.git
```

### Step 2: Navigate to the Project Folder

```bash
cd Data_Structure_Task
```

### Step 3: Run a Python File

Run any project using Python:

```bash
python List.py
```

Other files can be executed similarly:

```bash
python Tuple.py
python Dict.py
python To_Do_list.py
```
